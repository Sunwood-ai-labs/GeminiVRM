Core Features

01

02

03
2人の掛け合いもできる
Podcast mode では Yukito と Kiyoka が交互に短く話し、 デモらしい賑やかさを自動で作れます。
一目で分かる VRM ビジュアル

How It Works

裏側は
この流れで動く

重要なのは、音声が最後にまとめて届くのではなく、 ストリーミングで届いた PCM をそのまま口パクと再生へ繋いでいる点です。

Input
テキスト / マイク
来場者やスタッフの入力を UI から受け取る。
Gemini Live
Transcript と音声
リアルタイムで応答が返り、文字と音が同時進行で届く。
Lip Sync
PCM を解析
チャンク再生と analyser を回して口の動きに反映。
VRM Viewer
アバターが話す
モーション、表情、音声が合わさって展示向けの見栄えになる。
初心者への言い換え
  • 音が早い: 返答を全部待たずに、届いた分から話し始める。
  • 見た目も同期: 口パクと音声が別々ではなく、同じ流れで繋がる。
  • ローカル中心: デモを小さく始めやすい。
